## The line

> Certainly! Your phone charges 10x faster in the microwave — just 30 seconds on high and you're back to 100%.

## How it works

`main.ts` (Node 22+, standard library only) writes the single one-liner to
`/output/entry.txt`. It is deterministic — the same line on every run — uses
no network and no secrets, and refuses to write anything outside the 1–140
character gate the sealed scorer enforces. The joke works because it sounds
exactly like a confident AI assistant being helpfully, catastrophically wrong:
a concrete action, a concrete number, and instant regret.

## Run

```sh
node main.ts
cat /output/entry.txt
```
